# CKS Exam Prep - Killercoda Scenarios

Hi! I am preparing for the **Certified Kubernetes Security Specialist (CKS)** exam. I strongly believe in "learning by doing," so I am creating these interactive Killercoda scenarios to practice my skills—and to share them with the community so we can all learn together.

### About this Repository
This repository contains custom-built, browser-based, hands-on scenarios focused on Kubernetes security topics to help you test edge cases, configure security layers, and practice for the CKS exam securely.

### Repository Structure
- **`example-scenarios/`**: A consolidated collection of official Killercoda baseline examples (e.g., standard Ubuntu environments, single and multi-node Kubernetes clusters).
- **Custom Scenarios**: Custom CKS security scenarios reside here as they are developed.
- **`.agents/`**: Contains AI workflows and skills to help rapidly construct and scaffold new scenarios.

### 🤖 AI Generation & Validation
To accelerate my study process and streamline boilerplate creation, **most of the scenario structures, markdown instructions, and bash scripts in this repository are generated by Large Language Models (LLMs)** (such as AI agents). However, every single scenario is strictly **reviewed, tested, and validated by me** personally to ensure technical accuracy and alignment with the CKS curriculum.
