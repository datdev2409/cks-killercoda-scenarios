# CKS: Pod Security Admission (PSA)

Welcome to the **Pod Security Admission** scenario!

As a Kubernetes administrator, ensuring that workloads run securely is paramount. Pod Security Admission (PSA) provides a built-in mechanism to enforce the Pod Security Standards.

In this hands-on lab, you will:
1. Apply Pod Security labels to namespaces to enforce and warn on specific profiles.
2. Configure the global AdmissionController for PSA via kube-apiserver.
3. Troubleshoot and secure a non-compliant Pod deployment in a securely configured namespace.
